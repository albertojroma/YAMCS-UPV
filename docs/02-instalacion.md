# Software necesario

Para trabajar cómodamente en este repositorio se recomienda tener instalado:

* **Visual Studio Code**: es un editor de código que incluye la posibilidad de usar el terminal del sistema. Se recomienda instalar las siguientes extensiones para el proyecto
    
    * Better Comments
    * XML Language Support by Red Hat
    * La *suite* de extensiones de Python creadas por Microsoft

* **git**: para clonar el proyecto se recomienda tener instalado **git** en la máquina donde se va a trabajar

* **conda**
